# Meridian

Joins code, git, and Jira to show every call site of a dying internal API, its owner,
its risk, hidden cross-team chains between tickets, and why work stalled.

- Code is truth. Jira is the plan
- Append-only, dated map
- Same snapshot + config = same output
- Suggest only. No PRs, no filed tickets. Later: self-maintaining APIs
- Not in the map, not in the output. Always report what we missed
